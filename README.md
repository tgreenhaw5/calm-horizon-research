# calm-horizon-research
<img src="profile-pic.png" alt="Alternative Text" width="300" align="center">
CALM Horizon combines Continuous Attention Language Model (CALM) for speed enhancement, an SAE dictionary to label neural network features, an Artificial Moral Agent (AMA) and Hazard Probe for safety, a pageable virtual knowledge domain scheme for extending knowledge, and a Workbench application to interpret and steer model behavior.
